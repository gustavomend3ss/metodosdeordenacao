# Métodos de Ordenação

Trabalho de Estrutura de Dados (FAINOR). Ordena os 15.000 números do `numeros.txt` com Borbulhamento, Inserção ou Seleção e mostra as trocas e o tempo.

## Como rodar

Deixe o `numeros.txt` na mesma pasta e rode:

```
g++ ordenacao.cpp -o ordenacao
./ordenacao
```

No Windows, é só abrir o `ordenacao.exe`.
